Live-updating fixture list, straight from the FA Full-Time system.

Subscribe on iPhone / iPad

Tapping the button above on an iPhone or iPad will prompt iOS to add this as a subscribed calendar. If that doesn't work, subscribe manually:

  1. Open the Settings app
  2. Go to Calendar → Accounts → Add Account → Other
  3. Tap Add Subscribed Calendar
  4. Paste this URL: webcal://cytbot.github.io/rangers-calendar/orton-rangers-u11.ics

On a Mac, Google Calendar, or Outlook, use the plain HTTPS link instead:
https://cytbot.github.io/orton-rangers-calendar/orton-rangers-u11.ics

Once subscribed, your calendar app checks for updates on its own schedule (iOS typically refreshes every few hours). The underlying file here is refreshed weekly (Friday evenings), so fixture changes and new rounds appear automatically — no need to re-subscribe. If you want the very latest before a match, ask whoever maintains this to trigger a manual refresh.

Fixture data via the FA Full-Time system. This page and calendar are generated automatically by GitHub Actions.
